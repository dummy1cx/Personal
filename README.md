# Personal Website

This repository contains a simple static website that you can use to showcase your skills, certifications, and contact information.

## Development

Open `index.html` in your browser to preview the website locally. You can edit the HTML, CSS, and JavaScript files to customize it further.

## Deployment

If you use GitHub, you can host this site easily via GitHub Pages:

1. Commit your changes and push them to your GitHub repository.
2. In the repository settings, enable GitHub Pages and choose the main branch as the source.
3. Your site will be available at `https://<your-username>.github.io/<repository-name>/`.

Feel free to modify the content to better reflect your experience and achievements!
